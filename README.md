# amec-css

amec CSS 編輯及自動備份

- `auto-backup/` 下，是自動備份的內容，不會編輯修改。

- `通用樣式的增添修改.css` 是「通用樣式表」的編輯檔。
  - 可以寫註解，更容易維護。
  - 只包含曾更動的部分，不是完整的通用樣式表。
  - 不是最新通用樣式表，因為其他人也可能更動。
  - 使用方式是將各條規則分別複製到後台貼上。
  - 每次編輯前必須先與線上版本同步。

- `work-styles/` 中，是各著作的個別樣式表的編輯檔。
  - 特性同上。
