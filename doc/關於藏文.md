## 🟨Q：依據現代化DOM規範，藏文行間元素或標題、段落，最好是加上 lang="bo" 而不要只是用自訂的class，對嗎？

🟩A：
**完全正確。**

只用自訂 class（如 `.font-tibetan`）只是單純的「外觀樣式勾點（CSS Hook）」，而加上 **`lang="bo"`** 則是符合 **HTML Living Standard** 與 **W3C 國際化規範（i18n）**的標準做法。

對於藏文這類**複雜文字系統（Complex Text Layout, CTL）**，加上 `lang="bo"` 不僅是語意規範問題，更直接影響到瀏覽器底層的排版與渲染引擎。

---

### 為什麼強烈建議加上 `lang="bo"`？

#### 1. 觸發底層文字塑形引擎（Text Shaping）

藏文依賴大量的上下疊字（Subjoined Consonants）與母音符號。
現代瀏覽器的字型渲染引擎（如 HarfBuzz、DirectWrite、Core Text）在處理 OpenType 特性（GSUB 替換、GPOS 定位）時，**會參考 DOM 的 `lang` 屬性來決定套用哪一組語法規則**。

- 若**沒有** `lang="bo"`：引擎可能繼承根節點的語言（如 `lang="zh-TW"` 或 `lang="en"`），導致部分藏文字元的字形重疊計算失準、標點位置偏移。
- 若**有** `lang="bo"`：引擎會強制使用標準藏文排版模組進行連字與垂直定位。

#### 2. 正確的藏文斷行規則（Line Breaking / Word Wrapping）

藏文的斷行規則與中文、英文完全不同：

- 藏文是以音節點（Tsheg，`་`，Unicode `U+0F0B`）作為音節分隔符號。
- 瀏覽器的換行引擎（ICU 函式庫）依據 `lang="bo"` 才能正確識別音節邊界並換行，避免在文字中間被不自然切斷。

#### 3. 系統字型 Fallback（字型後備機制）

若使用者裝置未安裝指定的客製藏文字型，瀏覽器會啟用系統預設字型。
當標註了 `lang="bo"`，系統會精準調用針對藏文優化的系統字型（例如 macOS/iOS 的 **Kailasa**、Windows 的 **Microsoft Himalaya**、Android 的 **Noto Sans Tibetan**），而不是亂抓中文字型裡的預設擴展區。

#### 4. 無障礙輔助（A11y）與機器翻譯

- **螢幕報讀軟體（Screen Readers）**：盲人朗讀引擎完全看不懂 `.font-tibetan`，但遇到 `lang="bo"` 就會切換成藏語 TTS 語音引擎，否則會當成中文拼音或亂碼念出。
- **瀏覽器自動翻譯**：Edge 或 Chrome 內建翻譯是依靠 `lang` 標籤來識別段落是否需要翻譯。

### 現代化的工程最佳實踐

標註 `lang="bo"` 後，CSS 選擇器就可以完全捨棄自訂 class，改用標準的 **`:lang()` 偽類選擇器**。

#### 1. HTML 結構

不管是標題、整段還是行內詞彙，直接標準化：

```html
<!-- 整段都是藏文 -->
<p lang="bo">བཀྲ་ཤིས་བདེ་ལེགས།</p>

<!-- 混排：中文段落中的藏文行內元素 -->
<p>這是一段說明：<span lang="bo">བཀྲ་ཤིས་བདེ་ལེགས</span> 扎西德勒。</p>
```

#### 2. CSS：直接使用 `:lang()`

`:lang()` 選擇器具備**層級繼承感知**，只要祖先節點有 `lang="bo"`，底下都能自動生效：

```css
/* 統一指定藏文字型（全域或局部） */
:lang(bo) {
  font-family:
    "Qomolangma-Uchen Sarchen", "Microsoft Himalaya", "Kailasa",
    "Noto Sans Tibetan", sans-serif;
}

/* =========================================================
   情境 A：藏文主導段落（純藏文，或 藏文 + 英數）
   ========================================================= */
p.tibetan-dominant {
  line-height: 1.8;
}

/* =========================================================
   情境 B：中文主導段落（含中文的混排）
   ========================================================= */
p.has-chinese {
  line-height: 1.6;
}

/* 將原本的 .font-tibetan 換成語意化的 :lang(bo) */
p.has-chinese :lang(bo) {
  line-height: 1;
  display: inline-block;
  vertical-align: baseline;
}
```

#### 3. JavaScript 偵測腳本微調

配合標準語意，JS 的選取器也可以直接改為尋找包含 `[lang="bo"]` 的段落：

```javascript
// 尋找包含藏文行內標籤的段落，或本身就是藏文的段落
const paragraphs = document.querySelectorAll(
  'p:has([lang="bo"]), p[lang="bo"]',
);

const hanRegex = /\p{Script=Han}/u;

paragraphs.forEach((p) => {
  const text = p.textContent || "";
  if (hanRegex.test(text)) {
    p.classList.add("has-chinese");
    p.classList.remove("tibetan-dominant");
  } else {
    p.classList.add("tibetan-dominant");
    p.classList.remove("has-chinese");
  }
});
```

### 總結

加上 `lang="bo"` 才是現代 Web 標準的最佳實踐。它能將**語言語意**與**排版樣式**徹底解耦，兼顧字型渲染底層品質、斷行排版、螢幕閱讀輔助以及代碼的長期維護性。
