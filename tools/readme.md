## css-norm.html

"正規化CSS"的HTML單檔小工具。作為手動比對CSS的輔助工具。
拉一個或兩個檔案進去，即可自動輸出轉換好的檔案到預設的下載資料夾，瀏覽器會自動處理檔名重複問題。

## diff-css.js

正規化比對工具。
搭配已經設定的 VS Code build task 以快捷鍵 Ctrl+Shift+B 執行。

- 您在編輯器開著第一個 CSS 檔（例如 file1.css）。
- 按下快捷鍵，VS Code 會自動把第一個檔案帶入。
- 只會跳出一次提示視窗詢問「第二個檔案」。
- 會自動建立暫存資料夾及正規化檔案。
- 自動叫出比對視窗。

## 色彩對比度檢查器.html

HTML單檔小工具。相較於 Adobe 的 色彩對比度 工具，這個工具的特色是：

- 可直接用吸管取色
- 以 oklab 色彩空間來調整明亮度，更符合視覺感知，並可避免產生"髒色"。
